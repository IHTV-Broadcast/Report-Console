# ربات گزارش‌گیری روزانه

این ربات تلگرامی برای جمع‌آوری گزارش‌های روزانه از کارمندان طراحی شده است.

## ویژگی‌ها

- دریافت گزارش روزانه از کارمندان
- پشتیبانی از انواع مختلف مشکلات
- امکان ارسال مستندات
- تحلیل هوشمند گزارش‌ها با استفاده از هوش مصنوعی Gemini
- رابط کاربری ساده و کاربرپسند

## نصب و راه‌اندازی

1. ابتدا پایتون 3.8 یا بالاتر را نصب کنید.
2. مخزن را کلون کنید:
   ```bash
   git clone [آدرس-مخزن]
   cd report-bot
   ```
3. محیط مجازی بسازید و فعال کنید:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate  # ویندوز
   source venv/bin/activate  # لینوکس/مک
   ```
4. نیازمندی‌ها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
5. فایل `.env` را ویرایش کنید و اطلاعات مورد نیاز را وارد کنید.
6. ربات را اجرا کنید:
   ```bash
   python main.py
   ```

## پیکربندی

فایل `config.py` را می‌توانید برای تغییر تنظیمات زیر ویرایش کنید:

- لیست کارمندان
- لیست سرورها
- انواع مشکلات
- منابع رویدادهای زنده

## استفاده

1. ربات را در تلگرام پیدا کنید و روی دکمه شروع کلیک کنید.
2. مراحل را دنبال کنید و به سوالات پاسخ دهید.
3. در پایان گزارش شما ثبت و برای مدیر ارسال می‌شود.
